# MENFA - Plataforma de Simulación de Planta de Gas y Transporte

Este software es un simulador modular e interactivo diseñado para la capacitación técnica y el entrenamiento cognitivo-operacional de operarios e ingenieros de plantas de acondicionamiento de gas natural.

## Características Principales
* **10 Módulos Operativos Integrados:** Desde los separadores mecánicos primarios hasta el despacho final en gasoductos troncales.
* **Entrenamiento Cognitivo de Fallas:** Desafíos interactivos con respuestas mecánicas simuladas en tiempo real.
* **Cumplimiento Normativo:** Verificaciones de campo alineadas con las exigencias del manual de seguridad técnica y la norma **NAG-125**.

## Ejecución Local
1. Instale las dependencias: `pip install -r requirements.txt`
2. Ejecute la aplicación: `streamlit run app.py`
